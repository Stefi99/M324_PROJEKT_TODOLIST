# User Story 1: Todos bearbeiten

Als Benutzer möchte ich bestehende Todos bearbeiten können,
damit ich Tippfehler korrigieren oder Aufgaben anpassen kann.

## Tasks

- Bearbeiten-Funktion planen
- Frontend für Bearbeiten vorbereiten
- Backend-Anpassung prüfen
- Pull Request erstellen
- Review durchführen
